项目概述

技术实现

渲染管线 · 性能优化 · 代码架构

项目基于 Three.js + GLTFLoader 构建，使用 PBR 材质（MeshStandardMaterial）呈现座舱塑料、金属、玻璃等真实质感。 通过环境贴图（RoomEnvironment）模拟车内暗调反射氛围，配合点光源与自发光材质实现氛围灯的空气感。 整个场景运行在浏览器 WebGL 中，无需安装插件。

优化后

通过 Draco 压缩、模型减面、贴图合并与材质复用，将 GLB 体积从 18MB 压缩到 3MB， 首屏加载时间缩短 80%，在中端手机上仍可流畅交互。

JS 
// 加载 GLB 模型并遍历材质
const loader = new GLTFLoader();
loader.load('assets/car-cockpit.glb', (gltf) => {
  const model = gltf.scene;
  model.traverse((child) => {
    if (child.isMesh) {
      child.material.envMapIntensity = 1.2;
      if (child.name === 'AmbientStrip') {
        ambientLightMeshes.push(child);
      }
    }
  });
  scene.add(model);
});

// 切换氛围灯颜色
function setAmbientColor(hex) {
  ambientLightMeshes.forEach(m => {
    m.material.emissive = new THREE.Color(hex);
    m.material.emissiveIntensity = 0.8;
  });
}
